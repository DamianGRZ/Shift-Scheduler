# Shift Scheduler

Quarterly shift schedule for a shop, generated by a genetic algorithm and checked
against Polish labour law (working day, 48h/week, 35h weekly rest, trading Sundays,
public holidays). Local single-user app, no authentication. UI is in Polish.

## Getting started

```bash
npm install
npm run db:setup   # creates shift-scheduler.db and sample employees
npm run dev        # http://127.0.0.1:3000
```

Tests: `npm test`. Production: `npm run build`, then `npm start`.

## Layout

- `src/lib/calendar.ts` – public holidays, trading Sundays, day kind (any year)
- `src/lib/rules.ts` – schedule rules; `check()` is both the UI validator and the GA fitness
- `src/lib/ga.ts` – genetic algorithm and leave suggestions
- `src/db/` – Drizzle schema + SQLite (`employees`, `schedules`, `assignments`)
- `src/app/api/` – plain JSON endpoints
- `src/app/schedules/[id]/` – schedule editor (GA, stop, accept parts, resume)

Business assumptions and plan: `PLAN.md`. Legal source for the rules: `Projekt.md` (Polish).
