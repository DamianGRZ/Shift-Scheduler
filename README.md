# Shift Scheduler

Quarterly shift schedule for a shop, generated by a genetic algorithm and checked
against Polish labour law. Runs locally on your computer; the UI is in Polish.

- builds a whole quarter at once with the exact number of people per shift,
- respects the working day, 48h per week, 35h weekly rest, trading Sundays and public holidays,
- keeps everything you enter yourself (shifts, leave, days off) and plans around it.

## Install on Windows

1. Install [Node.js](https://nodejs.org) (the LTS version) and [Git](https://git-scm.com).
2. Open a terminal and run:

   ```bash
   git clone https://github.com/DamianGRZ/Shift-Scheduler.git
   cd Shift-Scheduler
   npm run shortcut
   ```

3. Double-click **Shift Scheduler** on your desktop.

The first start takes a few minutes: it installs everything and creates the database
with four sample employees. After that the app opens in a few seconds.
It runs in its own window; close the window to stop it.

## Run it without the shortcut

On any system (or if you prefer a terminal):

```bash
npm ci             # install dependencies, first time only
npm run db:setup   # create the database, first time only
npm run dev        # start the app
```

Open http://127.0.0.1:3000. Press `Ctrl+C` in the terminal to stop it.

## How to use it

1. **Pracownicy** – add employees.
2. **Grafiki** – create a schedule for a quarter.
3. Open the schedule, click **Generuj GA**, then **Stop** when you like the result.

In the schedule you can also:

- select cells and type a code to enter it yourself; it is locked 🔒 and the algorithm will not change it
  (`Delete` clears it),
- lock a good fragment with **Akceptuj zaznaczenie**, then continue with **Wznów GA**,
- clear what the algorithm filled in with **Reset GA** (your locked cells stay),
- set how many people work per shift in the **Obsada** field, or for a single day in the **Wymagana obsada** row.

| Code | Meaning |
| --- | --- |
| `D` | full day 6:30–18:30 |
| `R` | morning 6:30–12:30 |
| `P` | afternoon 12:30–18:30 |
| `N` | trading Sunday 8:00–13:00 |
| `U` | leave, counted as 8h worked |
| `W` | day off without leave |

## Your data

- Everything is stored in one file: `shift-scheduler.db` in the project folder.
- The desktop shortcut saves a copy to `backups/` on every start (the 30 newest are kept).
- **Restore a backup:** close the app, delete `shift-scheduler.db`, `shift-scheduler.db-wal` and
  `shift-scheduler.db-shm`, then copy the backup file in as `shift-scheduler.db`.
- **Start from scratch:** close the app and delete those three files. The shortcut creates a new
  database on the next start (without the shortcut, run `npm run db:setup`).

## Problems?

- **The app does not start from the shortcut:** the error is shown in a message and saved in `logs/`.
- **`npm ci` fails with `EBADPLATFORM` or `edgesOut`:** your npm has a known bug (version 11.4).
  Update it with `npm install -g npm@11`, or run `npx npm@11.21.1 ci` instead.
- **Port 3000 is busy:** run `npm run dev -- --port 3001` and open port 3001.

## For developers

| Command | What it does |
| --- | --- |
| `npm test` | unit tests (calendar, rules, GA) |
| `npm run lint` | ESLint |
| `npm run build` then `npm start` | production build and server |

- `src/lib/calendar.ts` – public holidays and trading Sundays for any year
- `src/lib/rules.ts` – schedule rules; `check()` is both the UI validator and the GA fitness
- `src/lib/ga.ts` – genetic algorithm and leave suggestions
- `src/db/` – database schema (Drizzle + SQLite)
- `src/app/` – pages and API routes
- `scripts/` – Windows launcher and desktop shortcut

Business assumptions: `PLAN.md`. Legal background for the rules: `Projekt.md` (Polish).
