# Shift Scheduler

Quarterly shift schedule for a shop, generated by a genetic algorithm and checked
against Polish labour law. Runs locally on your computer. The UI is in Polish.

## Installation

You need [Node.js](https://nodejs.org) (the LTS version) and [Git](https://git-scm.com).

**1. Download the project**

```bash
git clone https://github.com/DamianGRZ/Shift-Scheduler.git
cd Shift-Scheduler
```

**2. Install dependencies**

```bash
npm install
```

**3. Create the database** (only the first time)

```bash
npm run db:setup
```

This creates the file `shift-scheduler.db` with four sample employees.

**4. Start the app**

```bash
npm run dev
```

Open http://127.0.0.1:3000 in your browser. To stop the app, press `Ctrl+C` in the terminal.

Next time you only need step 4.

## How to use it

1. **Pracownicy** – add employees.
2. **Grafiki** – create a schedule for a quarter.
3. Open the schedule and click **Generuj GA**, then **Stop** when you like the result.

In the schedule you can also:

- select cells and type `D`, `R`, `P`, `N` or `U` to enter a shift or leave yourself
  (it gets locked 🔒 and the algorithm will not change it); `Delete` clears it,
- lock a good fragment with **Akceptuj zaznaczenie** and continue with **Wznów GA**,
- clear the algorithm's work with **Reset GA** (your locked cells stay),
- change how many people work per shift in the **Obsada** field.

Shift codes: `D` 6:30–18:30, `R` 6:30–12:30, `P` 12:30–18:30, `N` trading Sunday 8–13, `U` leave.

## Problems?

- **Port 3000 is busy:** run `npm run dev -- --port 3001` and open port 3001 instead.
- **`npm install` fails on `better-sqlite3`:** install the current LTS version of Node.js and try again.
- **Start over with an empty database:** stop the app, delete the `shift-scheduler.db` files and run step 3 again.

## For developers

| Command | What it does |
| --- | --- |
| `npm test` | unit tests (calendar, rules, GA) |
| `npm run lint` | ESLint |
| `npm run build` then `npm start` | production build and server |

Code layout:

- `src/lib/calendar.ts` – public holidays and trading Sundays for any year
- `src/lib/rules.ts` – schedule rules; `check()` is both the UI validator and the GA fitness
- `src/lib/ga.ts` – genetic algorithm and leave suggestions
- `src/db/` – database schema (Drizzle + SQLite)
- `src/app/` – pages and API routes

Business assumptions: `PLAN.md`. Legal background for the rules: `Projekt.md` (Polish).
